# Breadcrumb（breadcrumb）

分組：互動元件

告訴使用者現在在系統的哪一層，並讓他點回上一層。放在頁首，一頁只放一份。同一區有幾個頁面要互相切換時，最後一節可以變成切換鈕，取代頁面上方的分頁。系統的功能入口用 [Side Nav](side-nav.md)；同一頁裡切換幾組內容用 [Tabs](tabs.md)。

## 部位

1. **節**：一層位置。圖示＋名稱。前面的節是連結，最後一節是目前頁面。
2. **圖示**：[Icon](icon.md)，16px。可以不給。
3. **分隔箭頭**：節和節之間向右的箭頭，16px。只是裝飾，報讀軟體不念。
4. **切換鈕**：最後一節帶了兩頁以上的同區頁面時出現。名稱右邊多一個向下箭頭。
5. **切換選單**：按切換鈕打開。列出同一區的頁面，目前頁面是選中的樣子。

## 狀態

| 狀態 | 長怎樣、什麼時候出現 |
| --- | --- |
| 平常 | 見「顏色」表。 |
| 滑過 | 前面的節名稱加深並加底線；切換鈕疊一層 5% 的深色。最後一節沒有切換選單時不能點，滑過不變。 |
| 焦點 | 用鍵盤停到前面的節、切換鈕、切換選單的頁面時出現 2px 藍框。 |
| 切換選單打開 | 切換鈕的向下箭頭不變，選單出現在切換鈕下方。點選單外面、按 Esc、選了一頁，選單收起。 |
| 縮短 | 整列放不下時，前面的節先縮短成刪節號，目前頁面最後才縮。 |

## 可以這樣做、不要這樣做

### 可以這樣做

- 同一區有幾個頁面時，最後一節帶同區頁面，用切換選單取代頁面上方的分頁。
- 每一節的圖示跟 [Side Nav](side-nav.md) 同一個區、同一個頁面用同一顆。

### 不要這樣做

- 最後一節做成連結。使用者已經在這一頁，點了只會重新載入。
- 同一區的頁面同時用麵包屑切換選單和頁面上方的分頁。兩個地方做同一件事，使用者不知道該用哪個。
- 在麵包屑裡放動作按鈕。麵包屑只回答「我在哪」。

## 無障礙

### 網頁和 APP 都要做到

- **鍵盤**：Tab 依序停在前面的節和切換鈕。Enter 開啟那一層。
- **鍵盤**：切換鈕按 Enter 或空白鍵打開切換選單，焦點移到目前頁面。Tab、Shift＋Tab 在選單的頁面之間移動，Enter 開啟那一頁。
- **鍵盤**：Esc 收起切換選單，焦點回到切換鈕。最後一個頁面再按 Tab，選單收起，焦點到切換鈕的下一個元素；第一個頁面按 Shift＋Tab，選單收起，焦點回到切換鈕。
- **焦點**：用滑鼠點切換鈕打開選單時，焦點一樣移到目前頁面，接著可以直接用鍵盤。
- **焦點**：選單收起時，焦點在選單裡就還給切換鈕；焦點已經被使用者移到別處就不搶。
- **報讀軟體**：麵包屑是一個導覽地標，名稱預設是「目前位置」，可以換。
- **報讀軟體**：前面的節念出名稱和「連結」。最後一節念出名稱和「目前頁面」。
- **報讀軟體**：切換鈕念出目前頁面名稱、「按鈕」、「已收合」或「已展開」。
- **報讀軟體**：切換選單是一個群組，進入時念出名稱。目前那一頁念出「目前頁面」。
- **動態**：切換選單出現時淡入並微微放大，收起時淡出。150ms（Micro 等級），出現用 `var(--ease-enter)`，收起用 `var(--ease-exit)`。
- **動態**：使用者設了「減少動態」時，選單直接出現、直接消失。
- **觸控**：切換鈕 32px 高。觸控裝置上切換選單的每一列至少 44px 高。

### 網頁專屬

- **ARIA 與 HTML 語意**：外層是原生 `<nav>`，帶 aria-label；裡面是 `<ol>`，每一節一個 `<li>`。
- **ARIA 與 HTML 語意**：前面的節是原生 `<a href>`。最後一節加 aria-current="page"。
- **ARIA 與 HTML 語意**：切換鈕是原生 `<button>`，加 aria-expanded 與 aria-controls，並加 aria-current="page"。
- **ARIA 與 HTML 語意**：分隔箭頭加 aria-hidden。
- **ARIA 與 HTML 語意**：切換選單搬到 `<body>` 底下，層級由浮層定位服務給。它是 role="group"，名稱跟最後一節相同；頁面是原生 `<a href>`，目前那一頁加 aria-current="page"。

## 注意事項

- 由左到右一節一節排成一列，節和節之間用向右的箭頭分隔。第一節是最上層，最後一節是目前頁面。
- 每一節是「圖示＋名稱」。圖示用 16px，跟 [Side Nav](side-nav.md) 同一個區、同一個頁面用同一顆圖示，使用者才對得起來。圖示可以不給，但同一列建議每一節都給，看起來比較整齊。
- 前面的節是連結，點了回那一層，可以按住 Ctrl、⌘ 開新分頁。最後一節是目前頁面，不是連結。
- 最後一節可以帶「同一區的其他頁面」。帶了兩頁以上，最後一節變成切換鈕，名稱右邊多一個向下箭頭；按下去打開切換選單，列出同一區的頁面，目前頁面是選中的樣子。只有一頁時照一般的最後一節顯示。
- 切換選單的樣子跟 [Side Nav](side-nav.md) 的子選單一樣：外框同 [Action Menu](action-menu.md)，每一列是圖示＋名稱，目前頁面是綠底白字。選單裡的頁面也是連結。
- 名稱太長、整列放不下時，前面的節先用刪節號縮短，目前頁面最後才縮。被縮短的節滑過時不會顯示全名，名稱要寫短。
- 麵包屑只顯示位置，不放動作按鈕。頁首的「新增」這類按鈕放在麵包屑旁邊。
