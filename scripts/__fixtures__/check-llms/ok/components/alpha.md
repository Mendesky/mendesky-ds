# Alpha（alpha）

分組：互動元件

第一個元件。搭配 [Beta](beta.md) 使用。

## 用法

### Angular（v0.0.1）

`app-alpha`

[在範例網站看全部 1 個範例](https://example.test/ng/?path=/docs/alpha--%E8%AA%AA%E6%98%8E)

#### 屬性

| 名稱 | 型別 | 預設 | 說明 |
| --- | --- | --- | --- |
| `label` | `string \| null` | `null` | null 為不顯示 |
| `size` | `Size` | `undefined` | 尺寸 |

#### 程式碼範例

```html
<a [label](x)>undefined</a>
```
