# Page Skeleton（page-skeleton）

分組：展示元件

頁面 loading 時的佔位符。

## 用法

### Angular（v0.7.0）

`app-page-skeleton`

（無 Input/Output）

[在範例網站看全部 1 個範例](https://mendesky.github.io/mendesky-ds-angular/v0.7.0/components/?path=/docs/page-skeleton--%E8%AA%AA%E6%98%8E)

#### 屬性

沒有輸入屬性。

## 注意事項

- 頁面資料載入前的 shimmer 佔位動畫，防止 layout shift。
