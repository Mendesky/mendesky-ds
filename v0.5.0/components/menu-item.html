Menu Item ​

選單裡的每一項都用它。一項佔一列，可以是執行一個動作（編輯、封存、刪除），也可以是從幾個值裡選一個（排序方式、每頁筆數）。Action Menu 要放了 Menu Item 才算選單：報讀軟體會念出「選單」，方向鍵、Home、End、Tab 也改照選單的規則走，細節寫在 Action Menu 的無障礙說明。另一種用法是放在選單外面，例如篩選視窗裡的排序區：那裡不是選單，但想跟選單裡的選項長得一樣，就用一排 Menu Item 做成單選。至於有勾選、輸入框、套用按鈕的篩選面板，用 Check Chip、Button，不要把 Menu Item 放進去。

部位

  1. 外框：整列都可以點。放在 Action Menu 裡會佔滿一整列；放在選單外面時，寬度跟著文字走。
  2. 圖示：icon 放 DS 的圖示名稱，顯示在文字左邊，可以不放。顏色跟著文字走。
  3. 文字：label 寫這一項要做什麼，或代表哪一個值，一定要給。
  4. 說明：description 顯示在文字下方，可以不放。加了它，文字會變成粗體標題，一般項目是深色，tone 設成 danger 時維持紅字；說明用較淺的灰色。滑過、按下時兩行都換成淺色字。
  5. 自訂內容：接在文字後面，可以不放，例如標出類型或狀態的 Label。滑過、按下或選中時底色會變深，這時顏色設成 LightWhite 的 Label 會自動換成淺色字，不用自己另外寫樣式。其他顏色的 Label，還有自己寫死顏色的內容，都維持原本的字色。

狀態

狀態長怎樣、什麼時候出現
預設灰字，沒有底色。
滑過變成實心的灰底配淺色字。
按下灰底再深一階，字一樣是淺色。
焦點用鍵盤移到這一項時，外圍會出現焦點框。
選中selected 設成 true 時是深藍實心底配淺色字，滑過時藍底深一階，按下再深一階。選中只靠底色表示，不加打勾或其他符號。在 Windows 高對比這類強制色彩模式下，瀏覽器會換掉自訂的顏色，這時改用系統的選取色當底色，一樣是實心底。
危險tone 設成 danger 時是紅字，圖示也是紅色；加了 description 也一樣，只有下面那行說明維持灰色。滑過、按下跟 Button 的 ghost 危險按鈕一樣：滑過是實心的淺紅底，按下換成較深的紅底，字都變成淺色。
停用設了 disabled 就換成停用的灰色字，沒有底色，滑過、按下都不會變。在選單裡鍵盤還是停得到，但點了、按了都沒反應，選單也不會關。強制色彩模式下改用系統的停用字色。

可以這樣做、不要這樣做

✅ 可以這樣做

  • 從幾個值裡選一個時，每一項都設 selected：選中的那項設 true，其他設 false。這樣報讀軟體才念得出哪一項已選取，打開選單時焦點也會直接停在目前的值上。
  • 跟這組單選不同類的動作，例如排序選單裡的「還原預設」，放在最後一列，上面用一條分隔線隔開，分隔線標成 role="separator"。
  • 刪除、封存這類危險動作，tone 設成 danger，文字也要寫清楚會做什麼，不要只靠紅色讓人看出危險。
  • 選項暫時不能用時設 disabled。停用的選項在選單裡鍵盤還停得到，用報讀軟體的人也聽得到有這一項。
  • 要在文字後面標出類型或狀態，就把 Label 放進自訂內容。顏色設成 LightWhite 的標籤，底色變深時會自動變成淺色字，不用自己寫滑過、選中的樣式；GreyOutline、Transparent 這類灰字標籤不會跟著變，疊在深色底上會看不清楚。

❌ 不要這樣做

  • 不要在放了 Menu Item 的 Action Menu 裡，再放 Button 或其他可以按的東西。方向鍵只在選單項目之間移動，按 Tab 又會把選單關掉，用鍵盤的人走不到它們。「還原預設」這類動作也做成一個 Menu Item。
  • 不要加打勾符號或 emoji 來表示選中。選中只看深藍實心底，報讀軟體靠 selected 念出已選取。
  • 不要用 selected 做可以同時選好幾項的多選。放在選單裡時，報讀軟體會把它當成「一組裡只能選一個」來念。要多選就用 Check Chip。
  • 不要在選單外面拿它當一般的操作按鈕，例如送出、取消。選單外只用在想跟選單長得一樣的一組單選，其他操作用 Button。

無障礙

網頁和 APP 都要做到

鍵盤
  • 放在 Action Menu 裡時，用上下方向鍵移到這一項，按 Enter 或空白鍵執行。Home、End、Tab、Esc 的作用寫在 Action Menu 的無障礙說明。
  • 停用的選項在選單裡方向鍵還是停得到，按 Enter 或空白鍵不會有反應。
  • 放在選單外面時，它就是一般的按鈕：Tab 移過來，按 Enter 或空白鍵觸發。
焦點
  • 用鍵盤移到這一項時，外圍會出現焦點框。
  • 放在 Action Menu 裡時，選單一打開，焦點就停在 selected 為 true 的那一項；沒有選中項才停在第一項。Action Menu 的 autoFocusFirst 設成 false 時，焦點不會移進選單，由呼叫端自己帶進去。關掉之後焦點回到哪裡，看 Action Menu 的無障礙說明。
報讀軟體
  • 放在 Action Menu 裡時，念出 label 和「選單項目」。設了 selected 的單選項，另外念出已選取或未選取。
  • 接在文字後面的自訂內容也算進名稱，報讀軟體會接在 label 後面一起念，例如「項目 C 已封存」。
  • 放在選單外面時，設了 selected 的會念成切換按鈕，並念出已按下或未按下；沒設的就念成一般按鈕。
  • description 不算進名稱，報讀軟體會在名稱之後把它當成補充說明念出來。
  • 圖示不會念。停用的選項會念出它是停用的。

網頁專屬

ARIA 與 HTML 語意
  • 裡面是原生 <button>。放在 Action Menu 裡時，元件外框是 role="none"，<button> 是 role="menuitem"；設了 selected 就改成 role="menuitemradio"，用 aria-checked 標出 "true" 或 "false"。
  • 放在選單外面時，<button> 不加角色；設了 selected 就用 aria-pressed 標出按下或未按下。
  • 停用用 aria-disabled="true"，不用原生 disabled，所以在選單裡方向鍵還停得到。
  • 有 description 時，<button> 用 aria-describedby 指向說明文字。
