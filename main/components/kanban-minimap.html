Kanban Minimap ​

Kanban 欄位縮略導覽。

用法

app-kanban-minimap（Angular 版 v0.5.0）

在範例網站看全部 3 個範例

屬性

名稱型別預設說明
boardContainerHTMLElement | nullnull看板的捲動容器（傳入 ViewChild 的 nativeElement）
columnsMinimapColumn[][]欄位資料，每項含 label、color、cardCount

程式碼範例

看板視圖整合

<!-- 在 kanban 視圖區塊內 -->
<div class="kb-area" #kbArea *ngIf="isKanban">
  <!-- kanban board ... -->
  <app-kanban-minimap
    [boardContainer]="kbAreaRef?.nativeElement"
    [columns]="minimapColumns()"
  ></app-kanban-minimap>
</div>

// TS: minimapColumns
minimapColumns = computed(() =>
  columns().map(col => ({
    label: col.label,
    color: col.dotColor,
    cardCount: col.cards.length,
  }))
);
