Spinner ​

一個動作已經送出、正在等結果，又不知道要等多久時用，例如等後端存檔、等檔案產生。轉圈放在動作發生的位置旁邊，讓使用者知道「系統還在做，不是當掉」。已經知道版面長什麼樣的區塊在讀資料時，用骨架，不用轉圈；知道做到幾成時，用 Progress Bar。按鈕在等結果時，打開 Button 或 Icon Button 的 loading，不要自己把轉圈塞進按鈕。

部位

  1. 軌道：一整圈，顏色是文字色的 20%。轉圈轉得很慢或停下來時，看得出這是一個載入圈。
  2. 弧：四分之一圈，顏色是文字色，線頭是圓的。整個轉圈一直繞著中心轉。
  3. 報讀文字：畫面上看不到，只給報讀軟體念。預設是「載入中」，用 label 改。設了 decorative 就沒有這段。

狀態

狀態長怎樣、什麼時候出現
轉動0.8 秒轉一圈，一直重複，直到轉圈從畫面上拿掉。轉圈本身沒有其他狀態，不能點、不能停用。

可以這樣做、不要這樣做

✅ 可以這樣做

  • 轉圈旁邊寫一句在等什麼，例如「字級更新中…」「產生 PDF 中…」。只有轉圈時，使用者不知道要等的是哪件事。
  • 放在深色底上，把外層的文字色改成淺色。轉圈跟著文字色，對比才夠。

❌ 不要這樣做

  • 用靜態圖示假裝載入中。圖示不會轉，使用者看不出系統還在做；圖示名稱打錯時，畫面上還會變成一片空白。
  • 把轉圈放進已經淡化（調低不透明度）的元素裡。轉圈跟著變淡，對比會掉到 3:1 以下；要淡化的話，只淡化旁邊的元素。
  • 整個區塊在讀資料、而且版面已知時用轉圈。這種情況用骨架，使用者看得到內容大概會長什麼樣。

用法

app-spinner（Angular 版 v0.13.0）

在範例網站看全部 4 個範例

屬性

名稱型別預設說明
size'12' | '16' | '24' | '36''16'寬高（px），對齊圖示尺寸。線寬依序 1.5、2、2.5、3
labelstring'載入中'給報讀軟體念的文字，畫面上看不到
decorativebooleanfalse旁邊已經有文字在講同一件事時設 true：整個轉圈加 aria-hidden，沒有 role="status"，也沒有報讀文字

程式碼範例

旁邊有說明文字（轉圈設成裝飾用）

<span class="saving">
  <app-spinner size="16" [decorative]="true"></app-spinner>
  儲存中…
</span>

畫面上只有轉圈（報讀軟體念 label）

<app-spinner size="24" label="正在讀取清單"></app-spinner>

深色底：改外層文字色，轉圈跟著變

<div style="background:#535353;color:#ffffff;">
  <app-spinner size="16" [decorative]="true"></app-spinner>
  更新中…
</div>

Angular 注意事項

按鈕在等結果時，用 app-button 或 app-icon-btn 的 loading，不要自己把 app-spinner 放進按鈕。

顏色跟著外層的 color：弧是文字色，軌道是同色 20%。

無障礙

網頁和 APP 都要做到

焦點
  • 轉圈拿不到焦點，Tab 會直接跳過。
報讀軟體
  • 預設會念出 label（預設「載入中」）。
  • 旁邊已經有文字在講同一件事時（例如按鈕上的「儲存中…」、toast 的訊息），把轉圈設成 decorative，報讀軟體就跳過它，同一件事不會念兩次。
  • 轉圈剛出現時，報讀軟體不一定會主動念，各家做法不同。等待的結果很重要時（例如存檔失敗），結果要另外用 Process Toast 這類會主動通知的方式告訴使用者。
動態
  • 0.8 秒轉一圈。
  • 使用者在系統裡開了「減少動態」時，改成 2.4 秒轉一圈。不完全停下來：轉圈的用途就是告訴使用者「還在進行」，停住就看不出來了。

網頁專屬

ARIA 與 HTML 語意
  • 沒設 decorative 時，外層是 role="status"，裡面放一段視覺上隱藏的 label 文字。
  • 設了 decorative 時，整個轉圈加 aria-hidden="true"，沒有 role。
  • 圖形本身一律 aria-hidden="true"。
  • Windows 高對比這類強制色彩模式下，弧與軌道都跟著系統的文字色，仍然看得到。

注意事項

顏色跟著周圍的文字色：弧是文字色，軌道是同一個顏色的 20%。放在深色底上時，把外層的文字色改成淺色，轉圈會跟著變。

轉圈只是「還在進行」的訊號，看不出在做什麼。旁邊要有文字說明在等什麼，例如「字級更新中…」；畫面上沒有文字時，用 label 寫給報讀軟體。
