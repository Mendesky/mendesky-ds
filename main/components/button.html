Button ​

畫面上能點的操作都用它，不要自己寫原生的 <button>。只有選單裡的選項例外，那裡改用 Menu Item，要在選項文字後面放標籤也是放在 Menu Item 裡。打開 loading 後，轉圈會取代圖示，按鈕變成灰色的停用狀態，點了也沒反應。如果不給 text、自己放內容，裡面的文字顏色一定要繼承按鈕，寫 color: inherit。寫死顏色的話，ghost 和 elevated 在滑過、按下時的文字色會套不上。之前就出過這種事：ghost 滑過後變成深灰底配黑字。

部位

  1. 外框：整顆按鈕都可以點。高度跟著 size 走，XXS 17、XS 24、S 32、M 36、L 40 px。
  2. 左側圖示：用 leftIcon 放，可以不放。顏色會跟著按鈕的文字走，只有加了說明時例外，細節看「說明」那一項。
  3. 左側標籤：文字前面的小標籤，用 leftLabel、centerLabel 放，可以不放。畫出來的是 Label。
  4. 文字：text 寫這顆按鈕要做什麼。不給 text 的話，這裡可以改放你自己的內容。
  5. 說明：description 會顯示在文字下方，可以不放。加了它，整顆按鈕會改成靠左對齊，文字換成較深的標題色，說明是較淺的灰色，圖示則維持按鈕原本的顏色；滑過時，文字和說明都換回按鈕的文字色。版面也會跟著變：左側的圖示和標籤跑到文字上面一行，右側的標籤、圖示和快速鍵提示排到說明下面一行，所以按鈕可能不只兩行。
  6. 右側標籤：文字右邊的小標籤，用 rightLabel 放，可以不放。
  7. 右側圖示：用 rightIcon 放，可以不放。顏色規則跟左側圖示一樣。
  8. 快速鍵提示：shortcut 只是一段提示文字，按鈕不會幫你綁快速鍵。選單裡的選項要用 Menu Item，它沒有快速鍵提示。
  9. 載入轉圈：只在 loading 時出現。這時按鈕上只剩轉圈和 loadingText，其他部位都會先藏起來。

狀態

狀態長怎樣、什麼時候出現
預設底色和文字色由 variant 和 color 決定。
滑過filled 的底色會深一階。tonal、outlined、ghost 會變成實心底配淺色字，只有 outlined 的 success 不一樣，它維持白底、框線變綠。elevated 則是浮起來，多一層陰影。
按下底色再深一階。有兩個例外：outlined 的 neutral 和 elevated 會變成藍底配淺色字，elevated 的陰影也會消失；outlined 的 success 則從白底變成實心綠底配淺色字。
焦點用鍵盤移過來時，按鈕外圍會出現焦點框。用滑鼠點的話不會有。
停用設了 disabled 就是灰底灰字，點了沒反應，鍵盤也移不過來。
停用但可點disabled 再加上 clickableWhenDisabled。看起來跟停用一樣，但還是點得到、鍵盤也移得過來。點下去不會執行操作，而是在按鈕上方顯示 disabledMessage，告訴使用者為什麼不能按；這段說明會一直留著，直到按鈕恢復可用。
載入中設了 loading 會換成停用的灰底，轉圈和文字是深灰色。有給 loadingText 就顯示它，沒給就只剩轉圈，其他部位都不顯示。這段時間點了沒反應，鍵盤也移不過來。

可以這樣做、不要這樣做

✅ 可以這樣做

  • 載入中記得給 loadingText，像「儲存中…」這樣。不然畫面上只剩一個轉圈，用報讀軟體的人根本不知道按鈕在忙什麼。
  • 按鈕暫時不能用、又想讓使用者知道原因，就打開 clickableWhenDisabled，再配一句 disabledMessage。按鈕一樣是灰的，但點下去會在上方跳出你寫的原因，總比讓人對著一顆沒反應的按鈕猛點好。
  • 想讓按鈕跟外層一樣寬，加 fullWidth 就好。
  • 做成切換鈕（按一下開、再按一下關）時，用 ariaPressed 告訴報讀軟體現在是按下還是沒按下。如果按鈕代表清單裡「目前這一項」，改用 ariaCurrent。
  • 按鈕會打開放了 Menu Item 的選單時，ariaHaspopup 設成 menu，ariaExpanded 跟著選單開關設成 true 或 false。這樣報讀軟體才知道按下去會跳出選單；在 Safari 上，選單關掉後也是靠 ariaHaspopup 和 ariaExpanded 一起認出這顆按鈕、把焦點還給它，少一個就認不出來。

❌ 不要這樣做

  • 只放圖示，卻沒給 ariaLabel。報讀軟體會念不出這顆按鈕叫什麼，開發模式下 console 也會警告你。這種按鈕通常直接用 Icon Button 就好；真的要用按鈕的外觀，ariaLabel 一定要補上。
  • 在按鈕裡面再塞連結、按鈕或勾選框。用鍵盤或報讀軟體的人，沒辦法單獨操作裡面那一個。
  • 以為設了 shortcut，按快速鍵就會觸發。它只會在按鈕上顯示一段提示文字，真正的快速鍵要自己另外綁。

程式碼範例

基本用法

<app-button
  variant="filled"
  color="primary"
  size="M"
  text="確認"
  leftIcon="Done-OK"
  [disabled]="false"
  [fullWidth]="false"
  (btnClick)="onConfirm()"
></app-button>

只有圖示時給名稱

<app-button
  variant="outlined"
  color="neutral"
  size="XS"
  leftIcon="LeftArrow"
  ariaLabel="上一頁"
  (btnClick)="goToPrevPage()"
></app-button>

清單中標示目前這一項

<app-button
  [text]="item.label"
  [ariaCurrent]="item.id === currentId ? 'true' : null"
  (btnClick)="select(item.id)"
></app-button>

打開選單的按鈕（例：每頁筆數）

<div class="page-size-wrap">
  <app-button
    variant="outlined"
    color="neutral"
    size="XS"
    [text]="'' + pageSize()"
    [ariaLabel]="'每頁顯示筆數 ' + pageSize()"
    ariaHaspopup="menu"
    [ariaExpanded]="pageSizeMenuOpen()"
    (btnClick)="pageSizeMenuOpen.set(!pageSizeMenuOpen())"
  ></app-button>
  @if (pageSizeMenuOpen()) {
    <app-action-menu ariaLabel="每頁顯示筆數" (closeMenu)="pageSizeMenuOpen.set(false)">
      @for (n of pageSizeOptions; track n) {
        <app-menu-item [label]="'' + n" [selected]="pageSize() === n" (itemClick)="pageSize.set(n)"></app-menu-item>
      }
    </app-action-menu>
  }
</div>

Angular 注意事項

ariaLabel 要寫成元件的設定（ariaLabel="…" 或 [ariaLabel]="…"）。直接寫 aria-label 或 [attr.aria-label] 會留在外層 app-button 上，到不了內層 button，報讀軟體讀不到。

app-button 用 Angular 預設的樣式封裝（Emulated），內部的 .btn 等 class 帶有元件專屬的屬性選擇器；使用端要覆寫按鈕內部樣式，寫在使用端元件自己的樣式裡碰不到這些 class；要寫在全域樣式表並讓權重高於元件內的規則，或在元件樣式裡用 ::ng-deep。

無障礙

網頁和 APP 都要做到

鍵盤
  • Tab 移到按鈕上，按 Enter 或空白鍵觸發。
  • 停用和載入中的按鈕，Tab 會直接跳過。停用但可點的按鈕還是停得下來，按 Enter 會跳出不能用的原因。
焦點
  • 用鍵盤移過來時，外圍會出現焦點框，樣式跟 DS 其他元件共用同一套。
報讀軟體
  • 報讀軟體會念出按鈕上的文字，再告訴使用者這是按鈕。圖示不會念。
  • 只放圖示、沒有文字的按鈕，名稱只能靠 ariaLabel。沒設的話報讀軟體念不出它叫什麼，開發模式下 console 會警告。
  • 一旦設了 ariaLabel，報讀軟體就只念它，按鈕上的文字和載入中的 loadingText 都不念。所以有文字的按鈕，除非文字單獨看不出意思，不然不用設。
  • 設了 ariaPressed，會念出現在是按下還是沒按下。ariaCurrent 只要不是 false，就會念出這是目前這一項。
  • 設了 ariaHaspopup，報讀軟體會念出按下這顆按鈕會打開選單；ariaExpanded 則念出選單現在是開著還是關著。
  • 載入中又沒給 loadingText 時，畫面上只剩轉圈；這時如果也沒設 ariaLabel，報讀軟體就念不出名稱。
  • 停用但可點的按鈕，報讀軟體會念出它是停用的，但使用者還是按得下去。按了之後跳出來的原因說明，報讀軟體不會念。
動態
  • 載入轉圈 0.6 秒轉一圈。使用者在系統裡開了「減少動態」，它目前還是會轉。
觸控
  • 每個尺寸都比手機建議的觸控範圍小。iOS 建議 44 點、Android 建議 48 dp，按鈕最高的 L 也只有 40 px。

網頁專屬

ARIA 與 HTML 語意
  • 裡面用的是原生 button 元素，type="button"，所以放在表單裡也不會不小心送出表單。
  • 停用和載入中用的是原生 disabled。停用但可點則改用 aria-disabled="true"，這樣焦點和點擊都還在。
  • ariaLabel、ariaPressed、ariaCurrent、ariaHaspopup、ariaExpanded 會分別變成內層 button 的 aria-label、aria-pressed、aria-current、aria-haspopup、aria-expanded，沒設就不會出現。

注意事項

自己在按鈕裡放圖示時，顏色寫 color: currentColor，別寫死，這樣圖示才會跟著按鈕的文字變色。尺寸照按鈕大小挑：XXS、XS、S 用 size="12"，M 用 size="16"，L 用 size="24"，跟按鈕內建的左右圖示一樣。

改完記得把滑鼠移上去看一眼，圖示應該跟文字一起變色，不能停在原本的灰色。如果圖示上寫死了 style="color:#686868"，滑過就不會變，改成 color: currentColor 或 color: inherit 就好。
