Button ​

任何可點擊操作。禁止原生 <button>。loading=true 時 spinner 取代 icon、底色不變、點擊無效。**用投影內容（不給 text，例如選單選項放「標籤＋名稱」）時，裡面的文字顏色寫 color: inherit**，否則 ghost／elevated 的滑過、按下文字色套不到（2026-10-02：寫死深色字 → ghost 滑過變深灰底配黑字）。

用法

app-button（Angular 版 v0.3.0）

在範例網站看全部 19 個範例

程式碼範例

基本用法

<app-button
  variant="filled"
  color="primary"
  size="M"
  text="確認"
  leftIcon="Done-OK"
  [disabled]="false"
  [fullWidth]="false"
  (btnClick)="onConfirm()"
></app-button>

注意事項

Icon 一律使用 color:currentColor，不可寫死顏色。尺寸對應：XXS/XS → size="12"，S/M → size="16"，L → size="24"。

驗證重點：hover 時所有 icon 顏色應與文字同步變白，不得保留灰色。若 icon 有 style="color:#686868" 寫死，hover 不會變色 — 請改為 style="color:currentColor" 或 color:inherit。

ViewEncapsulation.None — 外部可透過 CSS 覆寫樣式。

語意選用指引（Semantic Usage Guide）

操作語意variant / color視覺特徵實際範例
取消 / 關閉 / 還原 / 清除elevated白底毛玻璃，低視覺重量，暗示「可退出」取消、清除篩選、重設、上一步
逆流程 / 危險操作（表單確認按鈕）filled / danger紅底實心，高警示感刪除確認、封存確認（Dialog 內）
逆流程 / 危險操作（選單列表項目）ghost / danger紅色文字，無背景，適合選單密集排列Action Menu 內的刪除、封存
完成階段任務（里程碑）filled / success綠底實心，傳達「達成」與「正向推進」送出申請、發布、完成並開始填寫
一般往下推進 / 搜尋 / 主要動作filled / primary藍底實心，主要動作視覺重量最高下一步、套用、登入、查詢
情境捷徑（卡片內輔助操作）tonal / neutral灰底軟質感，hover 變灰實心，低調工具感，不與 CTA 競爭同上方地址、從範本匯入、套用預設值
inline 新增（＋新增項目）ghost / primary藍色文字，無背景，適合內容中插入的輕量操作＋ 新增其他項目、全部已讀
並排時的次要選項outlined / primary藍色邊框，重量低於 filled，適合與 filled/primary 並排查看全部通知、Microsoft 365 登入（與「登入」並列）
中性導覽（非業務動作）outlined / neutral灰色邊框，低調，不干擾主要流程登出平台、歷史搜尋詞
