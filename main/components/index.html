元件 ​

每個元件一頁：何時用、注意事項，以及各框架的用法與可操作範例。

互動元件 ​

元件什麼時候用
Button Group2–5 個互斥選項，且視覺需連成一排時用。
Button畫面上能點的操作都用它，不要自己寫原生的 <button>。只有選單裡的選項例外，那裡改用 Menu Item，要在選項文字後面放標籤也是放在 Menu Item 裡。打開 loading 後，轉圈會取代圖示，按鈕變成灰色的停用狀態，點了也沒反應。如果不給 text、自己放內容，裡面的文字顏色一定要繼承按鈕，寫 color: inherit。寫死顏色的話，ghost 和 elevated 在滑過、按下時的文字色會套不上。之前就出過這種事：ghost 滑過後變成深灰底配黑字。
Carousel Dot圖片輪播指示、kanban 分頁點。多步驟 wizard 請改用 Stepper。
Cell Button日期/年月選擇器內部的格子按鈕。高密度網格選取場景（年份格、月份格、日期格）。
Check Chip篩選條件多選、標籤多選、表單內單一 boolean 偏好（如同意條款、Email 通知開關）。禁止用 checkbox 自刻。text 可為使用者自由輸入（inline-add 自訂項目）時無需額外設定——chip 預設就會折行。
Checkbox單純的勾選框，三態：沒有／全有／部分。「部分」用在「一組裡選了一些」的地方（例：權限清單的分類列）。要「勾選框＋文字」的可點按鈕、只需兩態時，改用 Check Chip。
Icon Button工具列、表格操作、純圖示互動。禁止用 div 包 icon 模擬按鈕。
Inline Add在 chip 群組 / 清單尾端讓使用者新增「自訂項」。取代 native window.prompt；單行文字輸入不要在 modal 內再疊 dialog。
Inline Confirm前提依賴型確認（contextualInline）：父層需要使用者在主操作前先勾選「已確認 XXX」。對應 ds-patterns action.precondition-acknowledge.scenarios[0]。
Menu Item選單裡的每一項都用它。一項佔一列，可以是執行一個動作（編輯、封存、刪除），也可以是從幾個值裡選一個（排序方式、每頁筆數）。Action Menu 要放了 Menu Item 才算選單：報讀軟體會念出「選單」，方向鍵、Home、End、Tab 也改照選單的規則走，細節寫在 Action Menu 的無障礙說明。另一種用法是放在選單外面，例如篩選視窗裡的排序區：那裡不是選單，但想跟選單裡的選項長得一樣，就用一排 Menu Item 做成單選。至於有勾選、輸入框、套用按鈕的篩選面板，用 Check Chip、Button，不要把 Menu Item 放進去。
Radio Chip篩選條件單選、可取消的選項。
Stepperhorizontal：多步驟 Wizard 進度指示。nav：Modal 左側多層導覽面板。
Toggle即時生效的開/關設定。
Upload Dropzone任何需要讓使用者上傳單一檔案的場景。不要自刻拖放區或使用原生 input type="file" 裸露呈現。

表單元件 ​

元件什麼時候用
Autocomplete搜尋後動態篩選選項的輸入框。
Date Picker需要選取民國年、年月、或完整日期（年月日）的場景。
Field所有表單欄位外層包裝。提供一致的 label 排版。標題只放欄位名稱（中粗 500）；單位（元）、限制（單檔上限 50MB）、提示（可複選）一律放 hint（標題旁淺灰說明），不要寫進 label 文字。跟畫面重複的說明（例如按鈕已列出的選項）直接不寫。
Input單行文字輸入。禁止原生 <input>。type='password' 時自動顯示 eye toggle。電話、編號等純數字欄位用 inputMode="numeric" sanitize="digits"。
Number Input金額、數量等數字欄位。有加減鍵與格式化。
Option Card Group一組互斥的插圖選擇卡（版面樣式 / 主題外觀等）。取代各處手刻的卡片 grid 與鍵盤 handler。
Option Card單張可選插圖卡。一般不單獨使用，由 Option Card Group 組成互斥群組（radiogroup）。hover 揭露純 CSS、無 JS；prefers-reduced-motion 下停用動效。
Rich Text Editor需要 rich text 輸入的場景（markdown 語法、表格、圖片由 wrapper 擴充）。純文字用 Textarea；含範本變數用 Template Editor；含圖片上傳時自行包一層 wrapper，透過 extraExtensions 與 extraToolbar 擴充。
Select固定選項下拉選擇。禁止原生 <select>。
Template Editor含範本變數的可編輯文字欄位（如信件內容、備註）。與 Textarea 功能相似但支援 inline badge。
Textarea備注、描述等多行輸入。禁止原生 <textarea>。
Year Month Picker需要選取民國年 / 年月 / 期別（1 期 = 2 個月）的場景。值為純字串，可以跟表單雙向綁定值。單純選年月時優先用此元件，不要自組年月下拉。

浮層元件 ​

元件什麼時候用
Dialog不可逆操作前確認（刪除、封存），或錯誤提示 alert（showCancel:false）。禁止自刻 modal 做確認。title 顏色固定使用 --text/title (#1c1c2e)，禁止 hardcode hex。Warning 只代表「紅色嚴重度」、不等於「刪除動作」：trash 圖示已與 propClass 解耦，僅真正刪除/移除實體才保留預設 Trash-Del，告知型 alert 與非刪除確認（取消封存、復原、送出、匯入）一律 confirmIcon=""。
Doc Preview 文件預覽預覽已上傳的附件（表單檔案、掃描文件）。可傳多份，元件自帶前後切換。PDF 與圖片可混在同一份清單，元件依 mimeType 或副檔名自行分派渲染方式。不負責下載或刪除，那些由呼叫端的清單元件處理。
Drawer Shell所有 Drawer 的容器。提供毛玻璃背景、透明 overlay、進出場動畫（Panel 450ms enter / 300ms exit）、ESC 關閉。禁止各 Drawer 自刻 overlay + panel + animation。
Keyboard Help 快速鍵說明集中展示目前畫面可用的鍵盤快速鍵。慣例以 ? 開啟。快速鍵資料由父層傳入，元件不自己蒐集——因為哪些快速鍵有效取決於當前路由與權限。
Modal Close Button所有 modal / dialog 的關閉 X 鈕。放進各 modal 自己的 header，關閉決策交 parent。禁止自刻 X button 或散用 Icon Button 當關閉鈕。
Modal Shell所有自訂 Modal 的容器。禁止自刻 overlay + card 組合。
Process Modal耗時操作的進度顯示（覆蓋整個畫面）。
Process Toast非同步操作的回饋通知。提供 action 時顯示 undo 按鈕（reversibleToast pattern）。loading 型別搭配 toast 服務的 show({persist:true}) + update(id, patch) 可做「進行中→完成」單一 toast 原地轉場（如匯出 PDF：文件產生中→已開始下載）——update() 僅限這種「同一件事的兩個階段」，不同事件各自一顆、堆疊（例如逐欄存檔時，每一欄的存檔結果各自一顆，不要用 update() 互相取代）。渲染一律經全域 Toast Container 全域 Toast 容器（掛 app root），元件不自建本地 toast stack；唯一例外是使用端自己的全域 API 錯誤浮層（若有，自有 z-index 9999 層，需壓在 doc-preview 之上）。層級規則（2026-08-13 定案）：Toast Container 全域 Toast 容器 為 2100，必須壓過 doc-preview 與 template-var-panel 的 2000 層——否則檔案預覽開啟時的操作回饋會被蓋住看不到（先前為 1600，實際被 doc-preview 蓋住）；全域 API 錯誤浮層與 tooltip portal 維持 9999（API 錯誤與游標提示更優先）。duration 由型別決定、呼叫端不自帶：success/loading 3000ms、error 5000ms、有 action 5000ms。容器內 toast 預設 pointer-events: none，僅帶 action 者可點（toast 位於卡片右下角，無條件可點會吃掉數秒點擊）。文案長度：.toast__msg 的 line-clamp:2 約在 29 全形寬靜默截斷；各類型的字數上限（例如 success/loading 16 全形寬、error 24、有 action 18）由使用端自訂；插值長度必須有界。
Toast Container 全域 Toast 容器app root 掛一次就好。任何要顯示 toast 的地方呼叫 toast 服務的 show() / update()，不要自建本地 toast stack——否則會出現兩套堆疊互相遮蓋。唯一例外是使用端自己的全域 API 錯誤浮層（若有，自有 9999 層）。
Tooltip Directive (Portal)替代 Tooltips 元件的 portal 版本。hover/focus 時自動顯示 tooltip，portal 到 body 避免容器裁切。
Tooltipshover 時顯示說明文字。

展示元件 ​

元件什麼時候用
Action Menu右鍵或 More 按鈕展開的浮層，有兩種用法。當選單用時，每一項都放 Menu Item。放了 Menu Item 才是選單：報讀軟體會念出「選單」和 ariaLabel 設的名稱，鍵盤與焦點也改照選單的規則走，規則寫在下面的無障礙說明。當篩選面板這類一般浮層用時，裡面放 Button、Check Chip、輸入框，鍵盤與焦點照一般浮層的規則走（見下方無障礙說明），不會被念成選單。兩種都不要自己手刻 <button>、<div> 當選項。
Avatar用戶頭像、個人資料。可點擊（例如右上角打開個人面板）時 clickable 設為 true 並給 ariaLabel，直接監聽本元件的 click 事件。
Badge未讀徽章：疊在按鈕或項目的右上角，表示「有未讀」或「未讀幾則」。目前用在 header 通知鈴與版本更新入口鈕、版本更新視窗的左欄版本列。
Ctrl Bar頁面或區塊頂部的操作列，左側放篩選/toggle，右側放搜尋/切換。
Divider區塊分隔。
Empty State列表/查詢無資料時顯示。
File List需要呈現已上傳檔案列表並提供操作時。支援「無類型模式」（例如 wizard 裡只收單一種文件）與「有類型模式」（依文件類型分類的附件，type 由父層傳入 FileItem.type）。disabled=true 為唯讀，只剩 view。需要 download 或依檔案類型切換動作時不要用這支——它沒有 actions 屬性；直接用 Number List（有 actions 屬性，NumberListAction 已含 download），需要下載的文件清單即如此。
Footer登入頁與 Shell 共用頁尾。禁止自刻 <footer> 複製文字。
Icon所有圖示顯示。禁止用 inline style width/height 控制大小，用 size 屬性。
Kanban MinimapKanban 欄位縮略導覽。
Label狀態、分類標籤。禁止用 div 自刻 badge。Badge 只放文字，不加 icon。放在 ghost 按鈕裡用 White（白底灰框），不用 GreyOutline：GreyOutline 是透明底，滑過時灰字疊在深灰底上看不清。放在 Menu Item 裡用 LightWhite：選項滑過、按下或選中時底色變深，LightWhite 的字會自動變成淺色，不用自己寫樣式。Purple / GreenOutline 用來區分兩種類別（例如「推薦」與「精選」）；GreenOutline 的字重 600 由這一格提供，呼叫端不要自己補 CSS。KanbanDraft/Opened/DealClosed/Archiving/Archived 五色為 CornflowerBlue 漸層（淺→深對應流程階段），SSOT 來自 Figma 17248:269232（看板列表的 status pill 專用）。text 綁使用者自由輸入的欄位時必須明示 wrap 設為 true（折行）或 truncate 設為 true 並加 tooltip（省略），不可留預設 nowrap — 預設 nowrap 讓 min-content ＝ 整串寬、chip 在 flex 容器內不可收縮，長值會撐破容器或被祖先 overflow:hidden 靜默裁掉。
List Tag清單項目附帶徽章標記。
List階層式資料展示。
Number List報表數字展示列、檔案列（含檢視／下載／編輯／刪除）。寬度 1024px 以上：label 與 text 放不下截成「…」，只有真的被截斷時滑過／聚焦才顯示全文 tooltip；寬度小於 1024px：改換行完整顯示。手機（小於 768px）按鈕只留圖示，「label＋text＋按鈕」的列改兩行（見下方 note，2026-10-13）。
Page Skeleton頁面 loading 時的佔位符。
Po Process採購/流程節點狀態顯示。
Progress Bar顯示一件分批進行的工作做到哪裡（例：批次授權「處理中 12 / 40」）。只畫比例，不內建文字；「處理中 12 / 40」這類說明由呼叫端排在旁邊。
Sort Header列表表頭裡可點擊排序的一格。點了發出這欄的 key，由呼叫端決定怎麼排、並把新的排序狀態傳回來；本元件不持有狀態，也不排序資料。

工具 ​

元件什麼時候用
DS Collapse 收合動畫內容區塊需要收合／展開動畫時用（例如可展開的卡片段落）。統一用這組 class，不要自己寫 height 動畫。
Portal Teleport 元素外送元素必須脫離目前 DOM 位置才能正確顯示時用（祖先有 transform、backdrop-filter 或 overflow:hidden）。需要跟著觸發點定位與追蹤捲動時改用浮層定位服務。
