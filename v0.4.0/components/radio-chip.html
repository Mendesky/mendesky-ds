Radio Chip ​

篩選條件單選、可取消的選項。

用法

app-radio-chip（Angular 版 v0.5.0）

在範例網站看全部 5 個範例

屬性

名稱型別預設說明
textstring''顯示文字
sizeRadioChipSize's''m' | 's' | 'xs'
showRadiobooleantrue是否顯示左側 Radio 圓圈圖示
showCancelbooleanfalse選中後右側顯示 × 取消按鈕
(cancelClick)EventEmitter<void>點擊 × 按鈕時觸發，由父層清空選中值

程式碼範例

單選篩選群組

<app-radio-chip
  *ngFor="let opt of statusOptions"
  [text]="opt.label"
  [showCancel]="true"
  [(ngModel)]="opt.selected"
  (cancelClick)="clearStatus()"
></app-radio-chip>

// 清除群組：
clearStatus() { this.statusOptions.forEach(o => o.selected = false); }

注意事項

Radio Chip 實作單選語意：點擊後 selected → true，不支援自身再次點擊取消（Radio 語意）。若需取消選中，showCancel 設為 true，並監聽 cancelClick 事件由父元件清空整個群組的選中值。
