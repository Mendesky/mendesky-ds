第一個畫面 ​

這篇帶你在一個元件裡放進設計系統的欄位、輸入框和按鈕，組成一個可以輸入、顯示錯誤、按下送出的小表單。完成開始使用的設定後讀這篇。

在元件裡引入設計系統的元件 ​

template 要用設計系統的元件，先在自己的元件裡引入。各框架的寫法見下方分頁：

ts
// standalone 元件是不需要 NgModule 的 Angular 元件：它在自己的 imports 裡列出 template 要用的東西。
// 設計系統的元件都是 standalone，從 @mendesky/ds-angular import 後放進 imports 就能在 template 使用。
import { Component } from '@angular/core';
import { ButtonComponent, FieldComponent, InputComponent } from '@mendesky/ds-angular';

@Component({
  selector: 'app-item-name-form',
  standalone: true,
  imports: [FieldComponent, InputComponent, ButtonComponent],
  templateUrl: './item-name-form.component.html',
})
export class ItemNameFormComponent {
  name = '';
  nameError = '';

  onNameChange(value: string): void {
    this.name = value;
  }

  onConfirm(): void {
    this.nameError = this.name.trim() ? '' : '請輸入項目名稱';
  }
}
ts
// <script setup lang="ts">
// Vue 版試做中，還沒有提供安裝與引入方式；這裡只示範元件的狀態與處理函式。
const name = ref('');
const nameError = ref('');

function onNameChange(value: string) {
  name.value = value;
}

function onConfirm() {
  nameError.value = name.value.trim() ? '' : '請輸入項目名稱';
}

組一個表單 ​

template 用三個元件：

  • Field：欄位的外框，負責標題與「必填」標示。
  • Input：單行文字輸入框。
  • Button：按鈕。
html
<app-field label="項目名稱" [required]="true">
  <app-input
    size="L"
    placeholder="請輸入項目名稱"
    [errorMessage]="nameError"
    (valueChange)="onNameChange($event)"
  ></app-input>
</app-field>

<app-button
  variant="filled"
  color="primary"
  size="M"
  text="確認"
  (btnClick)="onConfirm()"
></app-button>
vue
<DsField label="項目名稱" :required="true">
  <DsInput
    size="L"
    placeholder="請輸入項目名稱"
    :errorMessage="nameError"
    @value-change="onNameChange($event)"
  ></DsInput>
</DsField>

<DsButton
  variant="filled"
  color="primary"
  size="M"
  text="確認"
  @btn-click="onConfirm()"
></DsButton>

幾個要點：

  • 欄位標題只放欄位名稱。單位、限制、提示放 Field 的 hint，不要寫進 label。
  • 選填欄位不用標示，只有必填欄位把 required 設為 true。
  • 不要用原生的 <input> 和 <button>，一律用 Input 和 Button。

輸入框有錯誤時的樣子：

取得輸入值：initialValue 與 valueChange ​

Input 不能跟表單雙向綁定值，也不能接表單控制項。它用一個屬性和一個事件處理值，一進一出：
  • initialValue（屬性）：放進輸入框的值。外部改了這個值，輸入框內容會跟著更新。
  • valueChange（事件）：使用者改了內容就送出新的值。

例如從 API 拿到資料後預填：

html
<!-- app-input 不支援 ngModel，也不支援 formControlName -->
<app-input
  size="M"
  [initialValue]="prefillValue"
  (valueChange)="prefillValue = $event"
></app-input>
vue
<!-- DsInput 不支援 v-model -->
<DsInput
  size="M"
  :initialValue="prefillValue"
  @value-change="prefillValue = $event"
></DsInput>

需要在離開欄位時才處理（例如輸入郵遞區號後查地址），改聽 blur 事件，它會帶出當下的值。

哪些元件可以雙向綁定 ​

雙向綁定是讓畫面上的值和元件裡的變數保持同步。元件本身要支援，才能這樣用。

設計系統裡可以跟表單雙向綁定值的元件：

  • Select
  • Checkbox
  • Date Picker
  • Year Month Picker
  • Check Chip
  • Radio Chip

下面以 Select 為例。框架專屬的設定寫在分頁的註解裡：

ts
// ngModel 是 Angular 的雙向綁定。元件要實作 ControlValueAccessor（Angular 讓自訂元件接上表單的介面）才能用。
// 使用時要在元件的 imports 加上 Angular 的 FormsModule。
import { Component } from '@angular/core';
import { FormsModule } from '@angular/forms';
import { FieldComponent, SelectComponent, SelectOption } from '@mendesky/ds-angular';

@Component({
  selector: 'app-department-form',
  standalone: true,
  imports: [FormsModule, FieldComponent, SelectComponent],
  templateUrl: './department-form.component.html',
})
export class DepartmentFormComponent {
  department: string | null = null;

  departmentOptions: SelectOption[] = [
    { value: 'design', label: '設計部' },
    { value: 'engineering', label: '工程部' },
    { value: 'admin', label: '行政部', disabled: true },
  ];
}
ts
// <script setup lang="ts">
const department = ref<string | null>(null);

const departmentOptions: SelectOption[] = [
  { value: 'design', label: '設計部' },
  { value: 'engineering', label: '工程部' },
  { value: 'admin', label: '行政部', disabled: true },
];
html
<!-- app-select 也可以接 Reactive Forms 的 formControlName -->
<app-field label="部門" [required]="true">
  <app-select
    [options]="departmentOptions"
    placeholder="請選擇部門"
    [(ngModel)]="department"
  ></app-select>
</app-field>
vue
<DsField label="部門" :required="true">
  <DsSelect
    :options="departmentOptions"
    placeholder="請選擇部門"
    v-model="department"
  ></DsSelect>
</DsField>

顯示錯誤訊息 ​

Input 和 Select 都用 errorMessage 顯示錯誤：
  • errorMessage 有值時，欄位切成錯誤狀態並顯示這段文字。
  • 清成空字串 ''，錯誤狀態就解除。
  • 錯誤訊息是浮動的提示，不佔版面。errorPosition 決定它出現在欄位上方（'top'）或下方（'bottom'，預設）。
html
<app-input
  placeholder="請輸入項目名稱"
  [errorMessage]="nameError"
  errorPosition="top"
></app-input>
vue
<DsInput
  placeholder="請輸入項目名稱"
  :errorMessage="nameError"
  errorPosition="top"
></DsInput>

什麼時候該顯示錯誤、什麼時候清掉，見表單與錯誤提示。

處理按鈕事件 ​

Button 被點擊時送出 btnClick 事件。

常用的狀態：

  • disabled 設為 true：停用，點了沒反應。
  • loading 設為 true：載入中。spinner 取代 icon、底色不變、點擊無效，適合送出後等待回應的期間。
  • loadingText：載入中顯示的替換文字，選填。

停用時仍要說明原因 ​

主要動作條件不足時，可以維持停用的外觀但仍允許點擊，點下去顯示原因：

html
<app-button
  text="送出"
  [disabled]="!canSubmit"
  [clickableWhenDisabled]="true"
  [disabledMessage]="'請先填寫項目名稱'"
  (btnClick)="onSubmit()"
  (disabledClick)="onDisabledClick()"
></app-button>
vue
<DsButton
  text="送出"
  :disabled="!canSubmit"
  :clickableWhenDisabled="true"
  :disabledMessage="'請先填寫項目名稱'"
  @btn-click="onSubmit()"
  @disabled-click="onDisabledClick()"
></DsButton>
  • clickableWhenDisabled：停用時改用 aria-disabled，點擊事件仍會觸發。
  • disabledMessage：停用時點擊，按鈕上方會出現這段提示。多條訊息傳字串陣列，會用條列顯示。
  • disabledClick（事件）：停用時被點擊才送出。可以在這裡捲到第一個有錯誤的欄位。

按鈕的樣式（variant、color）怎麼依動作的意義挑選，見 Button 的說明頁。

其他表單元件 ​

元件什麼時候用
Autocomplete搜尋後動態篩選選項的輸入框。
Date Picker需要選取民國年、年月、或完整日期（年月日）的場景。
Field所有表單欄位外層包裝。提供一致的 label 排版。標題只放欄位名稱（中粗 500）；單位（元）、限制（單檔上限 50MB）、提示（可複選）一律放 hint（標題旁淺灰說明），不要寫進 label 文字。跟畫面重複的說明（例如按鈕已列出的選項）直接不寫。
Input單行文字輸入。禁止原生 <input>。type='password' 時自動顯示 eye toggle。電話、編號等純數字欄位用 inputMode="numeric" sanitize="digits"。
Number Input金額、數量等數字欄位。有加減鍵與格式化。
Option Card Group一組互斥的插圖選擇卡（版面樣式 / 主題外觀等）。取代各處手刻的卡片 grid 與鍵盤 handler。
Option Card單張可選插圖卡。一般不單獨使用，由 Option Card Group 組成互斥群組（radiogroup）。hover 揭露純 CSS、無 JS；prefers-reduced-motion 下停用動效。
Rich Text Editor需要 rich text 輸入的場景（markdown 語法、表格、圖片由 wrapper 擴充）。純文字用 Textarea；含範本變數用 Template Editor；含圖片上傳時自行包一層 wrapper，透過 extraExtensions 與 extraToolbar 擴充。
Select固定選項下拉選擇。禁止原生 <select>。
Template Editor含範本變數的可編輯文字欄位（如信件內容、備註）。與 Textarea 功能相似但支援 inline badge。
Textarea備注、描述等多行輸入。禁止原生 <textarea>。
Year Month Picker需要選取民國年 / 年月 / 期別（1 期 = 2 個月）的場景。值為純字串，可以跟表單雙向綁定值。單純選年月時優先用此元件，不要自組年月下拉。
